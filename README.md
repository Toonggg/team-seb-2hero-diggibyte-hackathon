# Databricks Hackathon

Central repository for our team's code, notebooks, and hackathon files.

## Setup

1. Clone the repository.
2. Create a virtual environment and install dependencies (if applicable):
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
3. Keep credentials and Databricks tokens in `.env` or `.databrickscfg` (both are gitignored).
